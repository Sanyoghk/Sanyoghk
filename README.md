**Java 21 · Spring Boot · PostgreSQL · Docker · Next.js / React / TypeScript**<br>
*May 2026 – present*

## How I Approach Engineering

- **Clear boundaries:** separate HTTP contracts, application use cases, domain rules, and persistence.
- **Server-side authorisation:** check access to the specific resource, including ownership and workspace boundaries.
- **Data integrity:** combine application validation with database constraints and versioned migrations.
- **Meaningful tests:** cover successful requests, invalid input, forbidden access, and workflow edge cases.
- **Reliable background work:** use durable jobs, bounded retries, and explicit failure states.
